## Реализовано

- Корневой Compose: Core/UI на 8080, Python agent, отдельная локальная Qwen; API-ключ не нужен.
- Автоматическое скачивание и SHA-256 весов, постоянный volume; Linux ARM64 и amd64 runtime
  одной версии llama.cpp. Основные образы закреплены digest, прямые/транзитивные Python-зависимости — constraints.
- Multi-stage образы, непривилегированные пользователи, healthcheck и порядок готовности.
- Настраиваемый общий таймаут для CPU; отдельная команда реальной проверки модели.
- Четыре направления из JSON, произвольные поддерживаемые даты ноября–декабря и 1–14 ночей.
- Сохранение старых пятиночных ID; пересчёт цены и повторная проверка дат перед оформлением.
- UI показывает фактическое число ночей и сравнение стоимости, дат и условий отмены.
- README со стартом, ресурсами, конфигурацией, ограничениями и проверочным сценарием.
- Новый набор из 12 запросов зафиксирован до первого запуска без изменения prompt.
