# Экран подготовки и проверки CI — 28 октября 2026

Процент скачивания считается из фактически полученных байтов. Рядом показаны полученный и полный объём в десятичных ГБ (1 ГБ = 10⁹ байт), например `21,7% · 1,23 / 5,68 ГБ`. Размер берётся из закреплённого манифеста, а не прописан в интерфейсе. Основная модель занимает 2 497 281 120 байт: `2,50 ГБ`.

После скачивания или использования кэша объём сохраняется на этапах загрузки в память и прогрева. `100%` относится к скачанному файлу; готовность помощника проверяется отдельно по model health и ответу агента. Процент прогрева не выдумывается. Проверка хеша подписана «Проверено», при неизвестном полном размере отображаются полученные ГБ без процента.

## Воспроизведение

```sh
node scripts/ui-startup.cjs
# Настоящий перезапуск основного Compose, volumes остаются на месте:
docker compose build app model
node scripts/ui-startup-compose.cjs
# Для проверки конкретной ранее оформленной тестовой поездки:
STARTUP_BROWSER_STATE=/absolute/path/to/browser-state.json node scripts/ui-startup-compose.cjs
```

UI-скриптам нужны локально установленный Playwright Core в `.runtime/browser/node_modules` и Google Chrome на macOS. Они не добавлены в Linux CI как переносимые браузерные тесты. Python/Go-проверки выполняются существующими workflows.

## GitHub Actions

Локальные эквиваленты CI проходят. Старый [Agent CI](https://github.com/ostrovok-hackathon-2026/misision-possible/actions/runs/40098036081) завершился до выполнения Python: GitHub сообщил о неуспешной оплате аккаунта или необходимости увеличить spending limit. У его lint job нет выполненных steps. Ручные запуски на `72f17e3` также остаются в очереди без назначенных jobs. Это отдельный организационный блокер; проверки не отключаются и не заменяются искусственным зелёным статусом. Владельцу организации нужно проверить Billing & plans / Actions, затем повторить workflows на опубликованном коммите.

Параллельные незавершённые изменения календаря, оформления и дизайна не включаются в коммит этой задачи.
