## Код, интеграция и интерфейс

- **46 Python-тестов** успешно локально и в финальном Docker-образе; ruff и pip check — успешно.
- Go Core: `go test -race ./...`, `go vet ./...` — успешно.
- Общий gRPC wire-контракт Python/Go совпадает; различается только go_package.
- Исходный `scripts/smoke.py` Луки: Auth/Core/gRPC/NATS/2FA — успешно.
- `scripts/trip-smoke.py`: реальная Qwen → Core → выбор A → бюджет 100 тысяч → B
  с delta −12 тысяч → невозможные 30 тысяч → очистка preview и отказ stale accept →
  восстановление бюджета → принятие → учебная покупка → идемпотентный повтор — успешно.

- `scripts/ui-smoke.cjs`: Chrome, реальный UI → Qwen → A → preview B → принятие →
  учебная покупка → перезагрузка с сохранённой покупкой — успешно, ошибок JavaScript нет.
  Скриншоты просмотрены: `.runtime/screenshots/budget-preview.png`, `booked.png`.
- Индикатор ожидания: на контролируемых задержках HTTP-ответов проверены реальный таймер,

## Исправленные ошибки и оставшиеся ограничения

Ранее полный прогон дал [12/15](../agent/evals/results/qwen9-v40-full.json), затем
[16/17](../agent/evals/results/qwen9-v42-before-final-fix.json). Исправлены неизвестный
возраст ребёнка, выдуманные точные даты из месяца, передача исходного JSON при retry,
сокращённые цитаты дат и перефразированные цитаты пожеланий. Для последних валидатор
теперь показывает неверную цитату и требует исходные слова. Неправильная цитата по-прежнему
отклоняется: автоматического принятия «похожих» слов нет.

Кроме этого, цена и delta заново берутся из каталога по ID, длительность сверяется
с датами, а «подешевле» не создаёт выдуманный новый бюджет.

В финальном открытом наборе нерешённых сбоев нет. Остаются ограничения прототипа:

- Каталог синтетический: только Москва → Сочи/Казань/Владимир, двое взрослых,
  окна 10–15 и 12–17 ноября 2026. Реальных тарифов, наличия, платежей и покрытия всей России нет.
- Неизвестные данные о детях/питомцах приводят к уточнению или отказу, а не к успешной покупке.
- Произвольные `hard_constraints.other` можно добавить, но их снятие пока не реализовано.
- Точная цитата не доказывает смысловую корректность модели. Набор открытый и использовался
  при настройке prompt; 17/17 не означает надёжность на любых запросах. Лимит 45 с
  может приводить к безопасной ошибке при дополнительной нагрузке на Mac.
- Файловое хранилище sessions предназначено для одного локального Core. Для внешнего
  запуска нужны production-хранилище и интеграция sessions с Auth Луки.
- Hosted Qwen-адаптер не проверялся с реальным ключом; основной путь полностью локальный.

## Воспроизведение

Из корня репозитория, последовательно (не запускать несколько inference-тестов одновременно):

```sh
python3 scripts/local.py start
cd agent
.venv/bin/python -m unittest discover -s tests -v
.venv/bin/python -m evals.run --output evals/results/qwen-project-local.json
cd ..
python3 scripts/trip-smoke.py
node scripts/ui-smoke.cjs
```

Зависимость для browser smoke, структура файлов и кнопки запуска описаны в
[local-setup.md](local-setup.md). Веса, inference runtime, venv, данные и логи остаются
в папке хакатона; общая Ollama для работы приложения не нужна.
