Цель: закрыть таймауты основного Compose, сохранив языковой контракт и пользовательский путь. GPU и сервер модели на хосте в проверках Docker не используются.

Зафиксированная до выбора модели цель: весь стек на четырёх общих vCPU, лимиты RAM в сумме не более 6 GiB, без swap контейнеров; 95/95 существующих фраз; прогретый p95 ≤30 с, максимум ≤90 с; холодный запуск ≤600 с на испытательной машине. CPU quota/cpuset на M4 не эмулируют старый процессор: переносимость времени на старые Intel/AMD требует отдельного замера.

Машина и общая VM Docker: [machine.json](machine.json). Фоновые контейнеры других задач не останавливались. Нативная Qwen на порту 18082 не используется в Docker-замерах.

Базовая конфигурация: Qwen3.5-9B Q4_K_M, llama.cpp b11853, 10 потоков автоматически, wire=0. Старт с существующими весами 254,578 с. Первый модельный запрос: 236,688 с; 1 215 токенов промпта за 177,444 с; 209 выходных токенов за 56,558 с. Внешние источники в этом микрозамере не вызываются. Следующий запрос начат, но остановлен перед завершением; он не считается успешным измерением.

Оптимизация настройки 9B: четыре потока, ubatch=128, 4 контрольные точки, cache-ram=256 MiB, compact wire=1. Промежуточный старт до добавления кэша проверки весов: 282,220 с, из них SHA-256 117,297 с. Эта конфигурация сама по себе не ускоряет загрузку; сравнение ответов продолжается.

Итоговые результаты, выбор модели и сквозной сценарий будут добавлены после завершения измерений. Этот файл пока не подтверждает снятие блокера.

## Обнаруженная помеха в предварительных замерах

В 20:10 UTC на хосте обнаружен значительный объём подкачки: 19,25 GiB занятого swap, около 12,56 GiB wired и 9,4 GiB compressor. Одновременно работала нативная 9B для интерфейса другого чата. Запрет swap внутри контейнера не запрещает macOS вытеснять память VM Docker. Сам объём занятого swap не доказывает активный paging во время каждого запроса. Однако без замера изменений swapin/swapout и давления памяти предварительные результаты выше и файлы candidate/lean нельзя использовать как чистое сравнительное доказательство скорости моделей. После обнаружения CPU inference остановлен. Нужен повтор после освобождения памяти; приложения пользователя и чужие контейнеры не останавливались.

Также во время работы другой чат исправил смысл расстояний до центра в model.py/compact_wire.py: длина системного префикса изменилась с 1228 до 1336 токенов. Новые серии фиксируют SHA-256 исходников, окончательная проверка будет включать эти исправления. Нельзя считать разные серии побитово одинаковыми по входу.

Предварительная Qwen3.5-4B Q4_K_M: загрузка новых весов и SHA 274,923 с, load 62,877 с, HTTP-ready model-only 342,246 с. Это не полный холодный запуск Compose. Первый запрос 232,796 с, прогретые короткие 9,161–34,001 с; сложный начальный запрос 77,327 с после прогрева. В сырых ответах есть лишние поля и неправильная область бюджета; модель пока не выбрана.

Эксперимент no-repack/ctx4096/checkpoints2/cache0: load около 6 с, первый запрос оборван по диагностическому лимиту 300 с. Эксперимент с repack и теми же уменьшенными буферами: первый запрос 300 с timeout, короткие 55,731 и 51,740 с. После этих серий обнаружен большой объём swap хоста; повтор необходим, причинное ускорение/замедление ими не доказано.
