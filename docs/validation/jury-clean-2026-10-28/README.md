Проверенный вариант запустился за **324,832 с (5 мин 25 с)** до healthy всех трёх сервисов. `/ready` вернул 200 через **311,536 с (5 мин 12 с)**. ## Что было чистым

- Новый клон GitHub в отдельной папке, базовый коммит `3761ed41a8e38cd62068b9ee7452079d86dc9133`. Поверх применено локальное исправление предела прогрева и связанные тесты/документация; перечень — в [preparation.json](preparation.json). Этот результат не относится к неизменённому удалённому коммиту.
- Новый builder `oplan-jury-fresh-20261028` с пустым build cache: базовые образы, зависимости и llama.cpp скачаны заново. [Лог сборки](startup.log.txt).
- Отдельный Compose project с изначально отсутствующими volumes. Модель не копировалась из предыдущего запуска или с компьютера разработчика.
- Нет `.env`, `.runtime`, LLM API-ключа и Travelpayouts token. Проверены настройки по умолчанию; пустой `.env.example` даёт ту же конфигурацию. [Проверка](defaults.json).
- Основной экземпляр на время замера остановлен; после проверки восстановлен. Остальные контейнеры разработчика оставались запущены.

Клон сделан через SSH с имеющимся командным доступом. Анонимный HTTPS-доступ к приватному репозиторию не работает; жюри нужен доступ через организацию GitHub хакатона. Модели, образы и зависимости при этом публичные, дополнительных учётных записей не требуют.

## Исправление и границы результата

Предел прогрева по умолчанию увеличен с 300 до 900 с в Compose и Python. Медленный CPU больше не требует правки `.env` только ради этого лимита. Успешный прогрев открывает приложение сразу; 900 с не являются обязательной задержкой. Предел одного пользовательского ответа остался 90 с. Общий срок установки от увеличения лимита не сокращается.

Окружение: MacBook Air M4; Docker Desktop 29.4.0, ARM64, 10 vCPU / 7,75 GiB RAM в VM; модель использует 4 потока CPU, GPU отключён. Ограничения контейнеров: модель 5 GiB, агент 512 MiB, приложение 256 MiB. CPU в этом замере не закреплялись через cpuset. Это замер на одном компьютере с быстрой сетью, а не гарантия для любого ноутбука.

Для ориентира до 10 минут рекомендуется стабильный интернет порядка 100 Мбит/с или быстрее, доступ к источникам и достаточная производительность CPU. На 20 Мбит/с только веса требуют не менее 16 мин 39 с. При блокировке Docker Hub, GitHub Releases, Hugging Face или пакетных реестров штатный запуск не обходит ограничения сети. Для запуска нужны Docker/Compose, минимум 6 GiB доступной Docker памяти и рекомендованные ресурсы из README.

На физическом Intel/AMD новый замер не выполнен. [Прежняя проверка AMD64](../amd64-2026-10-28/README.md) была через эмуляцию и подтверждает совместимость; её время нельзя переносить на реальную машину жюри. Новые defaults прогрева в эмуляции отдельно не проверялись.

Изолированные тестовые контейнеры, volumes и два builder, созданные в этой проверке, удалены. Основные пользовательские volumes сохранены.
