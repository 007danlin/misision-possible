# Проверка разнообразия направлений — 28 октября 2026

Результат: 9 из 9 HTTP-сценариев прошли на реальной Qwen3-4B-Instruct-2507 Q4_K_M через llama.cpp. Шесть общих пожеланий получили 2–3 подходящих направления; три узких запроса сохранили одно подходящее место. Дополнительно прошли 313 Python-тестов и Ruff.

## Что исправлено

Ранее диалог «Хочу на природу, в лес. Дикая природа.» → «Отправляемся из Москвы» возвращал только Карелию: [исходное воспроизведение](before-luka.json). Теперь тот же диалог вернул Карелию, Алтай и Селигер.

Модель различает общие темы и специфические требования. Для широкого запроса ожидаются 2–3 альтернативы; если получено одно место, допускается один дополнительный поиск по оставшимся кандидатам с теми же пожеланиями в общем deadline. Невалидный ответ или таймаут дополнительного поиска не удаляет первый корректный вариант. Код не дополняет список случайными направлениями.

Короткие запреты «не на Алтай», «не в Сочи» сохраняются как пожелания и исключают места из кандидатов. Ограничение короткой дороги проверяется по исходным сообщениям, даже если модель пропустила цитату. Для него выбирается ближайшее из предложенных совпадений и запрашивается допустимое время в пути; расстояние по прямой не выдаётся за проверенный маршрут. Нерелевантная цитата о море больше не блокирует корректный ответ.

## Воспроизведение и доказательства

После запуска Compose дождаться здоровья агента и завершения прогрева, затем:

```sh
python3 scripts/eval-direction-diversity.py --output .runtime/direction-diversity.json
PYTHONPATH=agent:agent/tests agent/.venv/bin/python -m unittest discover -s agent/tests
agent/.venv/bin/ruff check agent/travel_agent agent/tests scripts/eval-direction-diversity.py
```

Каждый сценарий создаёт новую HTTP-сессию. Проверяются число уникальных направлений, допустимость ID по пожеланиям и наличие вызовов модели в telemetry. Порядок не фиксируется. Моки и внешняя LLM не используются, бронирования не создаются.
