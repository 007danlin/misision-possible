# Сценарий скринкаста

Все действия выполняются в работающем приложении, без подставных ответов. Модель Qwen
локальная, данные синтетические; реальные деньги и услуги не используются.

1. Представление: «О!дин запрос помогает паре собрать поездку по России и изменить планы,
   сохранив важные условия. Сейчас четыре учебных направления».
2. Ввести полный запрос из Москвы в Сочи на 10–15 ноября для двоих, 120 тысяч на услуги.
   Показать ожидание ответа и три варианта. Суммы включают дорогу, отель, трансферы и сборы.
3. Выбрать A за 109 тысяч. Снизить бюджет до 100 тысяч, сохранив всё остальное.
4. Показать B за 97 тысяч: экономия 12 тысяч, разница по компонентам, сохранённые условия,
   компромисс — отсутствие бесплатной отмены. До принятия изменения купить нельзя.
5. Принять и подтвердить учебное оформление. Обновить страницу: заказ сохранён.
6. Коротко объяснить архитектуру: модель извлекает пожелания, инструменты проверяют факты
   и цену, Core сохраняет состояние и только после подтверждения создаёт учебный заказ.

Автоматическая запись: `scripts/record-demo.cjs`; результат — `.runtime/submission-video/demo.webm`.
Скрипт делает настоящие браузерные запросы; результат и время ходов записывает в `result.json`.
Для записи нужны Chrome, playwright-core и ffmpeg, для запуска самого продукта они не нужны.
