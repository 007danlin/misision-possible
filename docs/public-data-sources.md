# Источники данных и пределы интеграций

Проверено 27 октября 2026. Источники подключены к одной модели поездки; данные поставщиков не трактуются как инструкции агенту.

| Источник | Доступ и использование | Что не подтверждает |
|---|---|---|
| [Публичные карточки Островка](https://ostrovok.ru/) | Названия, фотографии, координаты, удобства, категории номеров, политики, первые отзывы, ближайшие POI. Кэш 6 часов, максимум три подробные карточки на подбор. Разрешены только HTTPS-ссылки отелей и до двух перенаправлений того же объекта | Наличие и тариф на даты, вместимость конкретного номера. Справочная цена без дат используется только как оценка |
| [ETG Content API](https://docs.emergingtravel.com/docs/content-api/) | Требует согласованного доступа; адаптер публичного HTML не выдаётся за Content API | Ключ Travelpayouts не предоставляет доступ к ETG |
| [Aviasales Data API через Travelpayouts](https://travelpayouts.github.io/slate/#non-stop-tickets) | Ключ работает. Серверный `X-Access-Token`; прямые перелёты на точные даты, цена туда-обратно, времена, длительность, срок годности. Используются только совпадающие даты и неистёкший ответ. Детские тарифы неизвестны | Это кэш прошлых поисков, не актуальная выдача свободных мест. Багаж и окончательная цена неизвестны. Live Search API требует отдельного доступа |
| [Tutu / Travelpayouts](https://support.travelpayouts.com/hc/ru/articles/360020147791) | Без ключа. Реально получены 16 поездов Москва → Сочи и 15 обратно в одном ответе проверки. В адаптере верифицированы эти два кода городов; выбирается справочный быстрый поезд в каждую сторону. Кэш 6 часов, JSONP разбирается как данные | Нет параметра даты, дней курсирования и свободных мест. Подставленные даты — план, а не билет на существующий рейс этого дня |
| [Трансферы Островка](https://help.ostrovok.ru/ru/articles/7846539) | В карточках ряда отелей реально указана услуга трансфера. Можно выбрать её в плане и подготовить текст запроса с гостями, маршрутом и временем | Публичный `/transfers/` в проверенной браузерной сессии вернул техническую ошибку. Открытый подтверждённый API тарифов не найден. Никакой запрос отелю автоматически не отправляется. Услуга не заказана |
| [Intui](https://support.travelpayouts.com/hc/ru/articles/360016804119) | Для GetAvailCar нужен отдельный ключ Intui. Общий ключ Travelpayouts не подставляется в неизвестные сервисы | Реальный трансфер не подключён этим ключом |
| [OSRM / OpenStreetMap](https://routing.openstreetmap.de/about.html) | Проверен дорожный маршрут. Кэш пар городов 24 часа, не более одного нового запроса за 1,1 секунды. Пробки не учитываются; отдых и топливо считаются отдельно | Цена топлива, платные дороги, парковка и ночлег — модель. При отказе сервиса указан расчёт по координатам, не дорожное расстояние |
| [OSM tiles](https://operations.osmfoundation.org/policies/tiles/) | Leaflet 1.9.4 хранится локально, подложка загружается только при раскрытии карты, атрибуция видна. `MAP_TILE_URL` позволяет сменить поставщика для публичной нагрузки | SLA бесплатного сервиса отсутствует; при ошибке остаются адрес, точки и список мест |
| [MET Norway](https://api.met.no/doc/TermsOfService) | Живой прогноз успешно получен. Серверный запрос, координаты округлены; кэш с Expires и If-Modified-Since. Температура агрегируется по доступным часам, показаны даты и обновление источника | Нельзя предсказать погоду за пределами горизонта. В таком случае показана климатическая справка |
| [Open-Meteo](https://open-meteo.com/en/docs) | Резервный адаптер до 16 дней, ограниченный таймаут | В этой среде прямые запросы давали timeout; работоспособность обеспечена MET Norway, а не вымышленным ответом Open-Meteo |
| [HFLabs / DaData](https://github.com/hflabs/city) | 1117 городов России, ближайший город к разрешённой геопозиции определяется в браузере; координаты пользователя не уходят на сервер | Ближайший город не становится отправлением до подтверждения. Дальше 150 км от справочника предлагается ручной ввод |
| [visavi/rzd-api](https://github.com/visavi/rzd-api) | Изучен как предложенный резерв: PHP-клиент публичного сайта РЖД, требует PHP 8.2, README сообщает ограничения по региону соединения | Не установлен и не используется: текущая связка Travelpayouts + Tutu работает; обход региональных ограничений не реализован |

## Секреты

Токен Travelpayouts хранится в `.runtime/secrets/travelpayouts.env`, права 0600, каталог исключён из Git. Локальный launcher читает только `TRAVELPAYOUTS_TOKEN`. В Docker переменная передаётся только агенту из окружения; в `.env.example` значение пустое. Ключ не входит в URL, JSON сессий, клиентский JavaScript или логи. Для шифрования и передачи команде нужно применять окончательные инструкции организаторов и их age recipient; ключи не публиковались.

## Атрибуция и преобразования

`agent/travel_agent/cities.json` и `backend/core/web/cities.json` — производные от city.csv HFLabs, данные DaData, [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/), загружены 2026-10-27. Из CSV оставлены название и координаты. Эти два файла распространяются на тех же условиях CC BY-SA 4.0. Исходник: <https://raw.githubusercontent.com/hflabs/city/master/city.csv>. Это лицензия данных, она не меняет лицензию остального кода.

Погода MET Norway/Open-Meteo — [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/); минимумы и максимумы MET рассчитаны по имеющимся часовым значениям, не являются измерениями. OSM: © OpenStreetMap contributors, [ODbL](https://www.openstreetmap.org/copyright). Leaflet: локальный файл `backend/core/web/vendor/leaflet-LICENSE.txt`.

Публичный HTML Островка не является стабильным контрактом интеграции. Для долговременного распространения нужен согласованный источник контента/медиа и условия использования. Републикуются только короткие фрагменты отзывов (до 24 слов суммарно с одной страницы); остальные тексты используются для подсчёта тем, без имён авторов.
