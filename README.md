# О!дин запрос — О!План

**Трек «О!дин запрос» · команда MISISION POSSIBLE.** Агент помогает выбрать направление, сравнить отели и собрать поездку с дорогой и трансферами. При изменении бюджета или дат сохраняет остальные пожелания и пересчитывает план.

Бронирование и оплата учебные. Цены справочные или расчётные; наличие на выбранные даты не подтверждено.

**Видео-скринкаст:** [демонстрация О!План](https://drive.google.com/file/d/15Kt7jRG_9qIraTlmsf3mNV0D80xjj5ke/view?usp=sharing).

## Быстрый старт

Нужны Git, Docker с Compose и интернет. Рекомендуется 4 ядра CPU, не менее 6 GiB RAM для Docker и 15 ГБ свободного диска. GPU не требуется.

```sh
git clone https://github.com/ostrovok-hackathon-2026/misision-possible.git
cd misision-possible
docker compose up --build
```

Откройте **http://localhost:8080**. При первом запуске автоматически скачивается модель (2,50 ГБ), затем выполняется прогрев. Страница показывает подготовку и открывает приложение после готовности. Веса сохраняются между запусками. Docker выбирает ARM64 на Apple Silicon и AMD64 на Intel/AMD.

Локальной модели API-ключ не нужен. Для настройки можно скопировать `.env.example` в `.env`; пустые значения используют настройки по умолчанию. Для жюри предусмотрен `secrets.env.age` с необязательным токеном авиаперелётов — [инструкция расшифровки](docs/secrets.md).

```sh
docker compose down
```

Остановка сохраняет поездки и модель. Подробности подготовки и решения ошибок — в [руководстве запуска](docs/runtime.md).

## Зависимости и переменные окружения

Compose запускает `app` (Go Core и UI, порт 8080), `agent` (Python/gRPC) и `model` (llama.cpp, Qwen3-4B-Instruct-2507 Q4_K_M). Сессии и кэши хранятся в Docker volumes; отдельные БД и брокеры не требуются. Внешние источники перечислены в [реестре данных](docs/public-data-sources.md).

Все пользовательские настройки корневого Compose:

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `LLM_PROVIDER` | `llama_cpp` | Провайдер модели |
| `LLM_BASE_URL` | `http://model:8082/v1` | Внутренний адрес модели |
| `LLM_MODEL` | `qwen3-4b-instruct` | Имя модели |
| `LLM_API_KEY` | пусто | Ключ внешнего провайдера, если используется |
| `AGENT_TURN_TIMEOUT_SECONDS` | `90` | Предел ответа, секунды (1–300) |
| `MODEL_WARMUP_TIMEOUT_SECONDS` | `900` | Предел прогрева для медленного CPU; готовность открывается сразу после завершения |
| `MODEL_LOCK` | `docs/docker-runtime.json` | Версия и SHA-256 модели |
| `MODEL_THREADS` | `4` | Потоки CPU |
| `MODEL_CONTEXT` | `4096` | Контекст на слот модели |
| `MODEL_CHECKPOINTS` | `2` | Контрольные точки контекста |
| `MODEL_CACHE_RAM` | `0` | Дополнительный кэш inference, MiB |
| `JOURNEY_DATA_SOURCE` | `public` | Публичные данные; `synthetic` — учебный каталог |
| `TRAVELPAYOUTS_TOKEN` | пусто | Токен кэша цен авиаперелётов |
| `MAP_TILE_URL` | `https://tile.openstreetmap.org/{z}/{x}/{y}.png` | Подложка карты; используется при пустом значении |
| `PUBLIC_DATA_USER_AGENT` | `OPlan-Hackathon/1.0 https://github.com/ostrovok-hackathon-2026/misision-possible` | Идентификатор клиента источников |

## Данные и сидирование

Миграции и ручная загрузка данных не нужны. Справочники включены в приложение; карточки отелей и другие публичные сведения загружаются при поиске и кэшируются. Режим `synthetic` задаётся явно через `.env`; ошибка источника не переключает приложение на вымышленные данные.

Volumes: `trips` — поездки, `hotel-content` — кэш отелей, `models` — веса, `startup` — состояние подготовки. `docker compose down -v` удалит эти данные.

## Маршруты и доступ

Регистрация и тестовые учётные данные не нужны. Браузер получает cookie владельца поездок; порт 8080 доступен только на локальном компьютере.

| Маршрут | Назначение |
|---|---|
| `/` | Главная страница |
| `/plan.html` | Умный подбор и оформление |
| `/health` | HTTP 200, `{"status":"ok"}` — процесс запущен |
| `/ready` | HTTP 200 после подготовки, 503 во время запуска |
| `/api/runtime/status` | Этап подготовки модели |
| `/api/sessions/` | Создание и история поездок |
| `/api/sessions/{id}` | Сохранённая поездка |
| `/api/sessions/{id}/turns` | Сообщение агенту |
| `/api/sessions/{id}/actions` | Выбор, изменение и учебное оформление |

## Проверочный сценарий

1. Введите: «Из Москвы в Сочи, 10–15 ноября 2026, двое взрослых. 120 тысяч рублей на дорогу, отель и оба трансфера. Без ночных рейсов, нужен бассейн».
2. Сравните варианты и состав цены, выберите отель.
3. Измените дату выезда на 17 ноября, проверьте пересчёт и примите изменение.
4. Подтвердите учебное оформление, обновите страницу и скачайте PDF поездки.
