# Глоссарий

Термины, которые встречаются во всех сервисах. Читай перед тем как лезть в конкретные эндпоинты.

## Токены

| Термин | Что это | Живёт |
|---|---|---|
| `access_token` | JWT, который шлёшь в `Authorization: Bearer <access_token>` в КАЖДЫЙ запрос к любому сервису (кроме публичных типа `/auth/login`) | 15 минут |
| `refresh_token` | Непрозрачная строка, нужна только чтобы получить новый `access_token`, когда старый протух | 30 дней |
| `pending_token` | Временный токен между шагом "ввёл пароль" и "ввёл код 2FA". Не даёт доступа ни к чему кроме `/auth/2fa/verify` | 5 минут |
| `session_id` | Внутренний ID сессии (зашит внутри JWT), нужен для logout / отзыва конкретной сессии. Фронту трогать не нужно, просто знай что он существует | — |

## Пользователь

| Термин | Что это |
|---|---|
| `user_id` | UUID пользователя, главный идентификатор везде |
| `status` | `unverified` — зарегался, но не подтвердил email (доступа нет) / `active` — обычный юзер / `banned` — забанен админом |
| `role` | `user` или `admin`. Admin-эндпоинты (`/admin/**`) требуют `role = admin` |

## Заголовки

Все защищённые эндпоинты (если не сказано обратное) ожидают:

```
Authorization: Bearer <access_token>
Content-Type: application/json
```

## Даты и время

Все даты в ответах — ISO 8601 UTC, например `2026-07-06T14:32:00Z`. Конвертируй в локальное время на фронте, бэк всегда отдаёт UTC.
