# Документация API

Это документация по HTTP API проекта `misison-possible`. Бэкенд: `ghost_err`.

HTTP API реализован в `auth` и `core`; `notif` обрабатывает события NATS,
а `chat` пока не запускает HTTP-сервер.

## Как этим пользоваться

- Каждый эндпоинт описан отдельной страницей: что делает, какие заголовки нужны, пример запроса и пример ответа (успех + основные ошибки).
- Все примеры — реальный JSON, который можно скопировать и отправить как есть (Postman / curl / fetch).
- Если что-то не совпадает с реальным поведением сервера — **не гадай**, спроси в чате команды. Документация обновляется вручную и может немного отставать от кода в процессе разработки.

## Быстрый старт для фронта

1. `POST /api/auth/auth/register` → `POST /api/auth/auth/verify-email` → получаешь `access_token` + `refresh_token`
2. Все остальные запросы — с заголовком `Authorization: Bearer <access_token>`
3. Когда `access_token` протухает (401 с кодом `ERR_TOKEN_EXPIRED`) — `POST /api/auth/auth/refresh` за новой парой
4. См. [Формат ошибок](./errors.md) — там расписано как парсить любую ошибку от любого сервиса
