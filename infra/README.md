# Инфраструктура

`model/` содержит сборку и запуск локальной модели, используемые основным `docker-compose.yml` в корне. Корневая команда `docker compose up --build` запускает весь демонстрационный продукт: Core, агента и модель.

`docker-compose.dev.yml` и `docker-compose.server.yml` сохраняют отдельный сервисный стек команды с Auth, Chat, Notif, PostgreSQL и мониторингом. Его дополнительные настройки описаны в `server.env.example`; этот стек не требуется для основного пользовательского сценария.

## Секреты для организаторов

По [требованию организаторов](https://docs.ostrovok.tech/s/b9e6ec5e-5ad6-4091-9c85-a48eee9b21cc/doc/shifrovanie-sekretov-klyuchej-6Qhc4gJOPZ) бинарный `secrets.env.age` и пустой шаблон `.env.example` располагаются в **корне репозитория**. Переносить их в `infra/` не нужно. Открытый `.env` исключён из Git.

Переданный токен Travelpayouts и порядок расшифровки описаны в [README](../README.md#передача-секретов-организаторам). Ключ внешнего LLM для основной конфигурации не требуется: Qwen работает локально в контейнере.
